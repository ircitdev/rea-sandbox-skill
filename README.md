# rea-sandbox

Скилл для Claude Code: безопасный запуск [REA](https://github.com/morluto/rea) без правки конфигов агента и честная проверка результата.

REA разбирает сайты, JavaScript, Electron, .NET и бинарники через Ghidra, Kuna и Hopper. У него много условий: на Windows Ghidra принимает только PE, Kuna и Hopper работают лишь на Linux и macOS, а `--json` может отдать 40 МБ на файл в 70 КБ. Скилл собирает это в один порядок действий.

Что умеет:

- поставить Node, REA, JDK, Ghidra и Kuna в одну папку со сверкой SHA-256;
- открыть сайт в отдельном Chrome с пустым профилем и удалить профиль после работы;
- свести файл Evidence в понятный отчёт: скрипты, эндпоинты, неизвестные, маркеры секретов;
- проверить MCP-сервер без регистрации и замерить размер списка инструментов;
- подсказать, как проверить находки и чего REA не видит.

## Установка

```bash
git clone https://github.com/ircitdev/rea-sandbox-skill ~/.claude/skills/rea-sandbox
```

После этого достаточно попросить Claude Code, например: «разбери через REA мою панель и покажи, какие API видны в коде страницы».

Нужны bash (на Windows — Git Bash), curl, unzip и Chrome. Для ELF и Mach-O на Windows — Docker.

## Важно

- Анализируйте только свои системы или цели, на которые есть разрешение.
- Анализ пассивный: скилл не вызывает найденные адреса и не вводит пароли. Вход выполняет человек.
- Это не аудит безопасности. Список эндпоинтов от REA может быть неполным.
- Скилл проверен на `rea-agents` 6.8.0; проверяйте актуальность командой `rea doctor`.
- `bootstrap.sh` целиком прогнан на Windows. На Linux те же шаги выполнены вручную в контейнере Ubuntu 24.04, сам скрипт там до конца не прогонялся.
- REA, Ghidra, Kuna и Hopper распространяются по своим лицензиям и в репозиторий не входят.
